# f_screener — 自选股财务质量打分

给一只 A 股做 9 道"财务健康"判断题，每对一道得 1 分，满分 9 分。分越高，说明这家公司的财务质量越好。

帮你快速筛掉财务有问题的公司，只留下基本面看着靠谱的。

## F-Score 是什么

一套来自投资学者皮奥特洛斯基的经典打分法。核心思路：不看估值（股价贵不贵），只看**财务质量**（这家公司账做得干不干净、赚得真不真）。9 道判断题涵盖三类：

| 类别 | 检查什么 | 大白话 |
|------|---------|--------|
| 盈利能力 | ROA > 0 | 资产在真赚钱 |
| | 经营现金流 > 0 | 卖东西真收到钱了 |
| | 今年 ROA 比去年高 | 赚钱能力在变好 |
| | 现金流 > 净利润 | 赚的是真金白银，不是纸面利润 |
| 杠杆/流动性 | 长期负债率下降 | 负债在变少 |
| | 流动比率上升 | 短期还钱能力在变强 |
| | 股本没增加 | 没靠增发股票稀释股东 |
| 经营效率 | 毛利率上升 | 产品越来越值钱 |
| | 资产周转率上升 | 资产越用越高效 |

每满足一项 +1 分：

- **8-9 分**：财务质量高，值得继续研究
- **5-7 分**：中等，需再看细节
- **0-4 分**：财务质量存疑，提高警惕

## 怎么用

```bash
# 单只 / 多只
python tools/f_screener/cli.py --codes 600519
python tools/f_screener/cli.py --codes 600519,002594

# 从清单文件读取（每行一个代码，# 开头是注释）
python tools/f_screener/cli.py --file watchlist.txt

# 只输出高分的（≥5 分）
python tools/f_screener/cli.py --codes 600519,002594 --min-score 5

# 显示 9 项逐条明细
python tools/f_screener/cli.py --codes 600519 --verbose

# 强制包含金融股（默认排除，见下）
python tools/f_screener/cli.py --codes 000001 --include-financial

# 指定对比多少年年报（默认 8 年）
python tools/f_screener/cli.py --codes 600519 --years 10
```

## 结果怎么看

终端和 CSV 都会展示**今年 vs 去年**的指标对比，比如：

```
代码      简称    总分  适用项  评分   营收(今/昨亿)      净利(今/昨亿)     毛利率(今/昨%)    ROA(今/昨%)     现金流(今/昨亿)
600519  贵州茅台  5    9      0.56  1720.54/1741.44  853.1/893.35    91.18/91.93    28.08/29.88    615.22/924.64
```

为什么看今年/去年两列？因为 F-Score 好几项都是比"今年是不是比去年好"（ROA 提升、毛利率提升等），单看今年看不出趋势。

## 金融股为什么默认排除

银行、保险、证券这类金融公司，天生就是高杠杆，资产负债结构和普通公司完全不同。套用普通公司的评分标准会失真（比如"负债率下降"这类题它们永远难做对）。工具会自动识别金融股并跳过，如果你就是想评，加 `--include-financial` 强制包含。

## 输出文件

结果存到 `data/screening/fscore_YYYYMMDD.csv`（按当天日期），Excel 可直接打开。被跳过的金融股单独存 `fscore_skipped_YYYYMMDD.csv`。

## 数据源

同花顺财务接口（经 AKShare），仅支持 A 股。

## 代码结构

```
tools/f_screener/
├── cli.py        # 入口（含今年/去年对比输出）
├── data.py       # 拉数据（四张财报表 + 字段映射）
├── f_score.py    # 9 项评分逻辑
├── financial.py  # 金融股识别
└── config.py     # 关键词表、手动名单、字段映射
```

## 免责声明

这个工具只做财务质量筛选，**不构成投资建议**。F-Score 高分只代表"财务质量好"，不代表股价会涨——它完全不看估值（贵不贵），请结合基本面研究使用。
