# industry_profit — 这家公司比同行更能赚钱吗？

输入一只 A 股，自动找出它属于哪个行业，然后把它近几年的赚钱能力和**同行业公司**比一比，看它到底是行业里的优等生还是差等生。

## 为什么需要比同行？

一家公司赚不赚钱，单看数字没意义。白酒和超市的利润率天然天差地别——白酒毛利率 90%，超市可能只有 20%。所以正确问法是：**"它比同行赚得多吗？"** 这个工具就是回答这个问题的。

## 怎么用

```bash
# 默认：对比申万二级行业，看最近 3 年年报的平均水平
python tools/industry_profit/cli.py 600519

# 看 5 年 / 换对比粒度（1 一级最粗 / 2 二级 / 3 三级最细）
python tools/industry_profit/cli.py 600519 --years 5 --level 3

# 一次看多只股票
python tools/industry_profit/cli.py --codes 600519,000858

# 同行财务数据强制实时重抓（默认主角实时、同行走缓存，见下方"数据新鲜度"）
python tools/industry_profit/cli.py 600519 --refresh-metrics
```

### 对比粒度怎么选

行业分类（申万）分三级：一级最粗（比如"食品饮料"），二级细分（比如"白酒"），三级最细（更具体的细分）。默认用二级，大部分情况下够用。

## 看哪几个指标

| 指标 | 大白话解释 |
|------|-----------|
| 净利率 | 每卖出 100 元货，最后净赚多少钱。扣掉成本、费用、税之后剩的。越高越能赚钱 |
| 毛利率 | 每卖出 100 元货，扣掉直接成本（原料、人工）后还剩多少。反映产品本身值不值钱 |
| ROE | 股东每投 100 元，一年能赚回多少。衡量"钱生钱"的效率 |
| ROA | 公司每 100 元资产（自有+借来的），一年赚回多少。比 ROE 看得更全面 |

前两个看"赚不赚钱"，后两个看"赚钱效率高不高"。ROA 同花顺没直接给，用 `ROE × (1 − 资产负债率)` 近似算出来。

## 结果怎么读

跑完会给你一张表，每个指标有四个基准可比：

- **公司值**：你输入的那只股票的数值
- **中位数**：把同行按数值排队，站在中间那家的水平。**推荐主看这一列**——它不会被极端值扭曲
- **截尾均值**：去掉最高的 10% 和最低的 10% 再平均，比简单平均稳，又比中位数用到了更多样本
- **简单平均**：所有公司加起来除以家数，一视同仁。**行业亏损面大时会被拖成负数**，那时参考价值有限
- **市值加权**：市值大的公司占比更重，代表"行业整体"。想跟龙头比就看这列

为什么中位数比简单平均可信？举个例子：5 家公司净利率分别是 −5、4.15、6、8、10，简单平均是 4.63，中位数是 6——**一家亏损公司就把平均值拉低了 1.4 个点**。行业内亏损公司多的时候（比如电力设备 379 家里有 104 家亏损），简单平均甚至会变成负数，那时它完全没有参考价值。

最后两列：

- **排位**：`第 N/M 名`（1 = 行业第一，M = 行业内样本总数）
- **百分位**：`xx%`，越小越靠前。比名次更通用——"379 家里第 186 名"和"42 家里第 21 名"含义天差地别，但"49%"和"50%"可以直接比

### 杜邦分解：ROE 是怎么来的

表下面会多打一节杜邦分解，把 ROE 拆成三个因子：

```
ROE = 净利率 × 总资产周转率 × 权益乘数
```

| 因子 | 含义 |
|------|------|
| 净利率 | 每 100 元收入最后赚多少（产品赚钱能力） |
| 总资产周转率 | 一块钱资产一年能做几次生意（运营效率） |
| 权益乘数 | 借来的钱是自有资金的几倍（杠杆） |

拆开的意义在于：**同样的 ROE，来源不同，风险完全不同。** 一家靠 20% 净利率 × 0.6 次周转 × 0.5 倍杠杆做到 6% ROE 的公司，和一家靠 4% 净利率 × 0.53 次周转 × 2.75 倍杠杆做到 6% 的公司，赚钱的质量差得远——后者是靠借钱撑起来的。

两个因子由已有指标反推，不额外抓数据：`周转率 = ROA ÷ 净利率`，`权益乘数 = ROE ÷ ROA`，三者相乘严格还原 ROE（是恒等式，不是近似）。

## 输出文件

结果输出到 `data/reports/{股票代码}/charts/industry_compare/`：

- `industry_compare.png`：顶部大标题写明"公司 vs 什么行业"，四格每格一个指标，四根柱子 = 公司（红）/ 同行中位数（绿）/ 同行简单平均（蓝）/ 同行市值加权（紫），标题里标"第 N/M 名"。行业没有的指标（如银行无毛利率）整格会显示"该行业无此指标"
- `industry_compare.csv`：上面那张表的原始数据（公司值、中位数、截尾均值、简单平均、市值加权、排位、百分位），方便用 Excel 打开

## 首次运行要等几分钟

工具需要知道"每个行业有哪些股票"，这个名单得现抓。首次运行会遍历约 335 个申万三级行业逐个拉取，约几分钟，**之后会缓存**，下次秒查。

行业名单有三个数据源，按精度依次降级，前一个不可用就自动切下一个：

| 顺序 | 数据源 | 粒度 | 市值口径 |
|------|--------|------|---------|
| 1 | legulegu | 完整 1/2/3 级 | 真实市值（亿元） |
| 2 | 申万三级行业指数（akshare 走申万官网） | 完整 1/2/3 级 | 指数权重 |
| 3 | 申万一级行业指数 | 只有一级 | 指数权重 |

- 缓存文件：`data/industry_map.json`（股票数 ≥ 1000 只才算有效，否则视为不完整并重建）
- 抓取源偶尔限流/抽风，工具会自动降速重试，中断了也支持断点续建（补抓缺的行业，不会重来）
- 失败率超过 30% 会**判定为构建失败、不写缓存**，直接切下一个数据源——避免把残缺数据当好数据用
- 降到第 3 档时，你选的 `--level 2/3` 会**自动降为一级**，终端、图片标题、CSV 三处都会标注"已降级"，不会让你误以为在跟更细的行业比。一级降级源的缓存文件是 `data/industry_map_index.json`
- 想强制重抓：加 `--refresh-cache`

## 数据新鲜度：主角永远最新，同行有 90 天缓存

行业里每只股票的近 20 年年报序列会缓存到 `data/industry_profit_metrics/`（每股一个小 JSON；删掉整个目录，下次自动重建）。

- **你输入的那只主角**：每次运行都实时去拉最新财报，**不用旧缓存**（拉完也存一份，方便日后它当别的股票的同行走缓存）
- **同行股票**：优先用 90 天内抓过的缓存，90 天后自动重抓。所以第一次跑某个行业最慢，之后重跑几乎秒出
- 想无视缓存、把所有同行也强制实时重抓一遍：加 `--refresh-metrics`
- 换 `--years`（看 3 年还是 5 年）不用重抓——缓存存的是逐年年报的原始序列，不是算好的平均

## 数据从哪来

| 需要的数据 | 来源 |
|-----------|------|
| 行业分类（申万 1/2/3 级） | AKShare |
| 每个行业有哪些股票 + 市值 | legulegu → 申万三级指数 → 申万一级指数（依次降级） |
| 各公司财务指标 | AKShare / 同花顺 |

申万 = 国内最通用的行业划分标准，证券公司选股基本都按它分。
