# profit_analyzer — A 股利润表分析工具

从已下载的年报 PDF 中自动提取利润表数据，生成多年度趋势图。

## 使用前提

先用 `fetch_reports` 下载目标公司的年报：

```bash
python tools/stock_reports/fetch_reports.py 600519 --years 5
```

年报会自动保存到 `data/reports/{股票代码}/` 目录。

## 使用方法

```bash
# 基础用法：分析最近 5 年
python tools/profit_analyzer/cli.py 600519

# 指定年份范围
python tools/profit_analyzer/cli.py 600519 --years 8

# 只查看特定指标
python tools/profit_analyzer/cli.py 600519 --metrics 营收,毛利率,归母净利润

# 只打印数据摘要，不出图
python tools/profit_analyzer/cli.py 600519 --no-chart
```

## 输出

- **终端数据摘要**：打印所有提取到的指标数据表格
- **趋势图**：自动保存到 `data/reports/{股票代码}/{股票代码}_利润表趋势.png`

## 支持范围

- **全 A 股通用指标**：营业收入、归母净利润、扣非净利润、ROE
- **制造业/消费类额外指标**：营业成本、毛利率、销售费用、管理费用、研发费用、财务费用、营业利润、净利润、净利率
- **金融企业**：仅支持通用指标（营收、归母净利润、ROE），明细指标因科目差异无法提取

## 提取的指标

| 指标 | 说明 | 默认可用范围 |
|------|------|:---:|
| 营业收入 | 主营+其他业务收入总和 | 所有公司 |
| 营业成本 | 直接生产成本 | 非金融 |
| 毛利率 | (营收-营业成本)/营收 | 非金融 |
| 销售费用 | 销售相关支出 | 非金融 |
| 管理费用 | 行政管理支出 | 非金融 |
| 研发费用 | 研发投入 | 非金融 |
| 财务费用 | 利息收支净额 | 非金融 |
| 营业利润 | 主营业务利润 | 所有公司 |
| 净利润 | 税后利润 | 所有公司 |
| 归母净利润 | 归属母公司股东的利润 | 所有公司 |
| 扣非净利润 | 剔除一次性损益的利润 | 大部分公司 |
| ROE | 加权平均净资产收益率 | 所有公司 |
| 净利率 | 净利润/营业收入 | 所有公司 |

## 自定义指标筛选

可用指标名：`营业收入`、`营业成本`、`毛利率`、`销售费用`、`管理费用`、`研发费用`、`财务费用`、`营业利润`、`净利润`、`归母净利润`、`扣非净利润`、`ROE`、`净利率`
