# screen_csi500 — 中证500 三层漏斗筛选

把中证500 全部成分股过三道筛子：先砍掉你不碰的（强周期行业、亏损、高负债），再看财务健康与成长，最后看估值便不便宜。输出明细 CSV、候选清单、四张图和一份报告。

纯描述性筛选，不构成投资建议。

## 怎么用

```bash
# 全量 500 只
conda run -n ai python tools/screen_csi500/run.py

# 小样本试跑
conda run -n ai python tools/screen_csi500/run.py --limit 30

# 强制重抓缓存
conda run -n ai python tools/screen_csi500/run.py --refresh
```

## 三层筛子

### 第 1 层：排除

- **强周期行业**：煤炭、钢铁、有色金属、基础化工、石油石化、房地产、非银金融、建筑材料、建筑装饰、交通运输
- **亏损 / 微利**：近 3 年扣非净利为正的年份少于 2 年
- **高负债**：资产负债率 ≥ 85%，或处于同行业负债率前 20%
- **ST / 退市风险**、上市不足 3 年

### 第 2 层：财务健康 + 成长

- 近 3 年 ROE 均值 ≥ 8%，且没有哪一年 ≤ 0
- 近 3 年 Σ每股经营现金流 ÷ Σ每股收益 ≥ 0.8（利润得是真钱）
- 营收、扣非净利的区间 CAGR 均 > 0

### 第 3 层：估值分位

- **自身历史分位**：PE(TTM) 与 PB 在近 5 年中的分位，取较低者 ≤ 35%
- **同行分位**：同申万一级行业内 PE/PB 分位，取较低者 ≤ 50%

所有阈值集中在 `config.py`，改阈值就是改结果。

## 输出到哪

`data/reports/_screens/csi500_YYYYMMDD/`：

- `csi500_metrics.csv`：全样本明细，每只股票过没过每一层、没过是因为哪条
- `csi500_candidates.csv`：候选清单

报告生成目前没有 CLI 入口，需要在 Python 里调用：

```python
from pathlib import Path
from tools.screen_csi500 import report
report.build(Path("data/reports/_screens/csi500_20260925"))
```

`report.build()` 产出四张图 + `中证500筛选报告.md`；`report_docx` 再把它导出成 `.docx`。

四张图分别是：估值分位分布、盈利水平 vs 估值分位散点、行业分布对比、价值陷阱散点（PE 分位 vs PB 分位）。

## 数据源

| 数据 | 来源 | 刷新 |
|------|------|------|
| 成分名单 | 中证指数官网 | 按日 |
| 财务指标 | 同花顺年报摘要（AKShare） | 90 天 |
| 估值历史 | 百度股市通 | 按日（源为双周频） |
| 行业标签 | 申万一级行业指数 | 复用行业映射缓存 |

## 已知局限

- 同行对比只有申万一级，粒度粗，跨细分行业可比性弱
- 同行样本只在中证500 内部，不含行业内大市值龙头；成分不足 5 只的行业无法比较
- 估值分位是双周频采样，近 5 年约 90 个点，精度有限
- 成分用当前名单，未做历史成分回测，存在幸存者偏差
- 财务指标是年报口径，不含最新季报，有时滞
- 强周期按申万一级整类剔除，可能误伤该行业内的非周期细分
- 指标缺失一律按淘汰处理，不做缺失放行
