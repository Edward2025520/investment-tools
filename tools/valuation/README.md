# valuation — 把净利润还原成现金，再谈值多少钱

肖星《一本书读懂估值》配套工具。核心思路是书上那句话：**利润表告诉你"记账赚了多少"，但公司真正多出来的、能分给投资人的钱，是"自由现金流"。** 工具分三步：

1. `quality` 盈利质量 —— 看净利润有没有真的变成钱
2. `intrinsic` 估值区间 —— 把自由现金流折现，给一个"多少钱"的区间
3. `relative` 行业相对估值 —— 和同行比贵贱

只支持 A 股，金额统一**亿元**，只做教学，不推荐、不预测、不给买卖结论。

## 一、盈利质量：quality

### 它在回答什么问题

一家公司净利润很好看，钱却没收回来——货赊出去了（应收涨）、压在仓库了（存货涨），利润全是账面数。quality 就是把"净利润"逐年还原成"自由现金流"，看你赚的钱是不是真钱。

### 怎么用

```bash
# 默认看最近 8 个年报期
conda run -n ai python tools/valuation/cli.py quality 600519

# 看 5 年 / 批量看多只
conda run -n ai python tools/valuation/cli.py quality 600519 --years 5
conda run -n ai python tools/valuation/cli.py quality --codes 600519,000858
```

首次跑某只股票要现拉三张原始年报表（利润表/资产负债表/现金流量表），约 10~30 秒；之后缓存到 `data/valuation_annual/{代码}.json`（90 天有效），换 `--years` 不用重抓。

### 怎么读

终端给逐年一张表，单位亿元：

| 列 | 大白话 |
|----|--------|
| 归母净利 | 归母净利润：账面上赚了多少 |
| 扣非净利 | 扣掉"非经常性损益"（卖资产、政府补贴等一次性收益）后赚多少 |
| 扣非差 | 归母 − 扣非：一次性收益占多少。常年有正差要警惕"靠变卖家当撑利润" |
| OCF | 经营活动现金流净额：真的收进来多少钱 |
| 资本开支 | 买设备、建厂房花的真钱 |
| FCF(经营近似) | = OCF − 资本开支。干完主业后真正多出来的钱 |

表下方一行 **现金含量** = ΣOCF ÷ Σ归母净利（跨这几年）：

- **≈1**：赚 1 元利润回收约 1 元现金，盈利质量健康。
- **< 0.8**：钱没怎么收回来（应收/存货占压），或行业属性（如大量垫资）。越低越要小心。
- **> 1**：利润外还有折旧摊销等"非付现成本"释放现金（重资产行业常见），不一定是坏事。

CSV（`quality.csv`）在逐年表右边多几列 **桥明细**，专门讲"净利为什么 ≠ OCF"：

- **折旧摊销** = 折旧 + 无形摊销 + 长摊摊销。账面成本，当年没掏现金，要从净利加回。
- **ΔWC经营** = 存货减少 + 应收减少 + 应付增加。正数 = 营运资金释放现金（回款好/占供应商便宜）；负数 = 钱被压在存货和应收上。
- 存货减少 / 应收减少 / 应付增加 是它的三个来源，单列方便看是哪一项在拖后腿。

一张图（`quality.png`）：逐年 归母净利 / OCF / FCF 三根柱并排，一眼看"利润→现金"的落差和趋势。现金含量直接写进图题。

### 口径提醒

- **FCF(经营近似)** 用的是最省事的近似 `OCF − 资本开支`，未单独剔利息税盾（日常看报表够用）；肖星书严格的 NOPAT 口径需要逐年税盾拆解，本期不做，避免出一个对不上的数误导你。
- 某年某科目缺失（如个别公司报表不披露某明细）该格显示 `-`，现金含量自动只算两项都全的年份。
- 累计利润为负（这几年加总亏钱）时现金含量无意义，工具会明说而不是硬给个数。

## 二、估值区间：intrinsic

### 它在回答什么问题

质量过关后问"它值多少钱"。思路是：把未来每年能产生的自由现金流，用一个折现率（WACC，资金成本）折回今天，加总成**企业价值**；再减去欠的钱（净债务）得到**归股东的价值**，除以总股本就是**每股值多少**。这就是现金流折现（DCF）。

**FCF 口径沿用 quality**：FCF ≈ 经营现金流净额 − 资本开支。基数 FCF0 默认取**最近一个正 FCF 年**（打印是哪年，避免拿亏损年硬折）。

### 怎么用

```bash
# 默认假设（偏保守）：WACC 10%、显性增速 3%、永续增速 2%、显性期 10 年
conda run -n ai python tools/valuation/cli.py intrinsic 600519

# 换假设看数值怎么动（增速假设越低、折现率越高 → 估值越低）
conda run -n ai python tools/valuation/cli.py intrinsic 600519 --wacc 0.12 --terminal-g 0.01
```

首次会现拉年报科目（可复用 quality 的缓存）+ 腾讯实时行情（现价/总市值，算股本）。

### 怎么读

终端会逐步还原"钱"：

```
企业价值 EV（未来 FCF 折现值之和）
− 净债务（短借+长借−货币资金，>0 欠钱要扣，<0 净现金要加回）
= 股东价值
÷ 总股本（从现价与总市值反推）
= 每股内在价值
```

- **每股内在价值（基准假设）**：在给定 WACC/增速下的一个数。它不是"目标价"，只是这套假设的必然结果。
- **网格区间**：WACC × 永续增速扫一遍（默认 7~11% × 0~4%，若你 --wacc 超出会自动扩带），取最低~最高，是**区间**而非单点——因为任何假设都不是精确的。
- **每股净资产（下限参考）**：账上真金白银的净资产对应每股。理论上股东价值不该长期低于它（那就等于按清算价折价卖），所以画在图上当地板，只做参照不做买卖线。

**怎么判断"现价"**：把现价横线放进图里看它在区间内/上/下，体会"市场价 vs 这套假设的折现值"之差。这**不构成**买入卖出建议——数字对假设极其敏感，改个增速估值能差一倍。

### 输出文件（`data/reports/{代码}/charts/valuation/`）

- `intrinsic.png`：每股价值随 WACC 的三条曲线（显性增速 −2pp / 基准 / +2pp），一条现价虚线、一条每股净资产点线；假设写左上角文本框。
- `intrinsic.csv`：假设表 + 基准每股 + 网格区间上下限 + 每股净资产 + 口径备注。
- `sensitivity.csv`：WACC(行) × 永续增速(列) 的每股价值网格，想自己做区间就看这个。

### 口径与提醒

- **内在价值 ≠ 目标价**：这是教学区间，不是预测。真正给买卖结论还需质量、行业、管理层、估值方法互相印证，工具只负责把"一套假设 → 一个数"算对、算透明。
- FCF0 若近 20 年无一年为正（长期烧钱扩张/亏损），DCF 无可折现基数，工具会**说明后退出**而不是硬算。
- 银行等公司报表不提供"货币资金/归母权益"时，工具无法扣净债务、也算不了每股净资产，会明示并按 EV 近似（此类公司现金流折现本就不适用）。
- 报表不列"短期借款/长期借款"行项（即无此类借款，如账上净现金的公司）时，该科目按 0 计并在输出里注明——不加这句会误伤资产负债表最干净的公司，把它们的大笔现金漏掉不算。
- 未加回非经营性资产（长期股权投资、交易性金融资产等）：多数主营业态下影响有限，教学从略。

## 三、行业相对估值：relative

### 它在回答什么问题

看一家公司"贵不贵"，最好跟**同行**比：同一个行业里，大家生意模式、报表结构相近，倍数才有可比性。relative 把目标公司放进它所在的申万行业，跟全部成分股比 PE、市净率，回答一个纯描述性的问题：**"它在同行里处于什么位置？"**

注意是**描述位置，不下结论**——分位低不等于该买（可能是行业整体被看衰），分位高也不等于该卖。

### 怎么用

```bash
# 默认按申万二级行业对比（如白酒 ≈ 19 家）
conda run -n ai python tools/valuation/cli.py relative 600519

# 指定一级/二级/三级粒度
conda run -n ai python tools/valuation/cli.py relative 600519 --level 1
conda run -n ai python tools/valuation/cli.py relative 600519 --level 3
```

首次跑会构建/加载申万行业成分股映射（缓存 `data/industry_map.json`），并批量拉同行实时行情。行业映射不完整时，可用 `--refresh-cache` 走 legulegu 完整重建 1/2/3 级映射（限流下可能需几分钟到十几分钟）；不愿等时工具自动降级到申万一级指数成分股，粒度只有 1 级，终端会注明。

### 怎么读

终端给两个指标各一行：

| 列 | 大白话 |
|----|--------|
| 目标 | 这家公司的 PE / 市净率 |
| 同行中位 / P25 / P75 | 全行业正常盈利成分股分布的位置（对数刻度） |
| 目标分位（低=便宜） | 目标值排在同行的第百分之几。如 PB 在 91% = 比 91% 的同行都贵 |

表下方一行**样本**：正 PE 几家 / 正 PB 几家，以及剔除掉多少家（PE 非正 = 亏损、PB 非正 = 负净资产、行情缺失）。亏损公司没有有意义的 PE，剔除出分布但单独计数，避免拉偏中位数。

### 口径与提醒

- **PE 用静态口径** = 总市值 ÷ 最新年报归母净利（与行业映射同一份年报数据，同行可比）；腾讯行情字段索引按 600519 实测核对，静态 PE 与"市值÷归母净利"交叉验证一致。
- **行业粒度取决于映射缓存完整度**：完整缓存到申万 3 级；不完整时自动降级到 1 级（终端明确写"已从 2 级降为 1 级"）。降级源只到一级，`--level 2/3` 会退化成一级。
- 只有正 PE/PB 进分布；亏损/负净资产的公司计数但排除，终端明确区分，不做"负倍数也硬排分位"的事。
- 样本过少（比如某三级行业只 2~3 家）时图会退化，仍可看，但分位参考意义有限。

## 数据从哪来

- 逐年三张报表科目：AKShare 同花顺原始年报接口（`stock_financial_benefit/debt/cash_ths`），按 12 月 31 日年报过滤。
- 科目定位用"候选列名子串"逐股通解，不针对单家公司写死列名。
- 实时行情（现价/总市值/PE/市净率）：腾讯行情 `qt.gtimg.cn` 批量接口。原计划用东方财富快照，但该接口在当前网络被挡（实测连不通），已切换腾讯并在程序里按字段索引解析、跨市加前缀（sh/sz/bj）。
